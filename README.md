# CAT Architect - AI Question Paper Generator

**CAT Architect** is an AI-powered tool designed to automatically generate academic question papers (Continuous Assessment Tests) from syllabus documents. It leverages Large Language Models (LLMs) to understand syllabus content, extract Course Outcomes (COs), and generate questions that align with Bloom's Taxonomy.

## 🚀 Recent Updates & Fixes
The project has been significantly upgraded to ensure high-quality and strictly formatted output:

### 1. **Strict Question Diversity**
- **No Repetition**: The AI is now explicitly instructed to avoid repetitive starters like "What is..." or "Explain...".
- **Varied Phrasing**: Questions now use a wide range of cognitive verbs (e.g., "Analyze", "Construct", "Differentiate", "Determine") to ensure academic rigor.
- **Scenario-Based MCQs**: Part A questions are encouraged to be scenario-based or problem-solving oriented rather than simple definitions.

### 2. **Exam Pattern Enforcement**
- **CAT 1**:
  - **Part A**: 10 MCQs (from Unit 1).
  - **Part B**: **Strictly 2 Questions** (10 Marks each) from Unit 1.
- **CAT 2**:
  - **Part A**: 10 MCQs (5 from Unit 2, 5 from Unit 3).
  - **Part B**: **Strictly 6 Questions** (10 Marks each) - 3 from Unit 2, 3 from Unit 3.
- **Logic Update**: Post-processing logic now automatically truncates any extra questions generated by the AI to match these exact counts.

### 3. **Template & Formatting Accuracy**
- **Word Export**: The system now correctly fills the official University Word Templates (`CAT 1 AI.docx` and `CAT-II CD QPP.docx`).
- **Table Mapping**: Questions, Options, Marks, COs, and Bloom's Levels are mapped precisely to the correct columns in the template tables.
- **JSON Safety**: Fixed issues where MCQs had invalid JSON formats (e.g., unquoted numbers). All options are now strictly double-quoted strings.

### 4. **Cleanup**
- Removed temporary debugging scripts and redundant files to ensure a clean codebase.

## 🛠️ Features
- **Syllabus Parsing**: Supports PDF, DOCX, and TXT files. Automatically extracts Units (1, 2, 3) and Course Outcomes (COs).
- **Intelligent Generation**: checks difficulty levels and rotates Bloom's Taxonomy levels based on configuration.
- **Dual Export**: Download papers as **PDF** (ready to print) or **Word** (editable).
- **History**: Automatically saves generated papers to a `history/` folder and organizes Word docs into `cat1/` and `cat2/`.

## 📂 Project Structure
- `app.py`: Main Streamlit application.
- `utils.py`: Core logic for syllabus extraction, Groq API interaction, and question generation.
- `formatting.py`: Handling PDF and Word document creation.
- `cat1/` & `cat2/`: Output directories for generated Word documents.
- `history/`: JSON logs of generated papers.
- `templates/`: (Root dir) Contains the `.docx` templates used for export.

## ⚡ How to Run
1. **Activate Virtual Environment**:
   ```powershell
   venv\scripts\activate
   ```
2. **Run the App**:
   ```powershell
   python -m streamlit run app.py
   ```
3. **Usage**:
   - Upload your Syllabus.
   - Click "Analyze Syllabus".
   - Select Exam Type (CAT1 or CAT2) and Difficulty.
   - Click "Generate Question Paper".
   - Download the result.

## 📝 Requirements
- Python 3.8+
- Streamlit
- Groq API Key (stored in `.env`)
- `python-docx`
- `fpdf`
